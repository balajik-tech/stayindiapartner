1. Executive Summary & Core Architecture

Stay India Owner is a feature-complete property management mobile application designed for PG, hostel, and property owners. The application covers the complete operational lifecycle from owner onboarding, multi-property room/bed configuration, guest check-in/check-out via QR codes, automated rent collection (Cash/UPI), sub-meter electricity bill generation, DigiLocker KYC identity verification, maintenance ticket tracking, staff access delegation, software subscription billing through Razorpay, and community associations.

1.1 Technology Stack Matrix

Layer Technology / Package Used Architectural Purpose
Framework Flutter (Dart SDK 3.3+) Cross-platform iOS and Android mobile compilation.
Architecture Clean Architecture + Feature-First Separation into Data, Domain, and Presentation layers per feature module.
State Management Flutter BLoC / Cubit (`hydrated_bloc`) Predictable state management with local UI state persistence.

Real-Time Messaging Socket.IO Client & Firebase FCM WebSocket live chat/notifications & push notification delivery.
Third-Party SDKs Razorpay Flutter SDK, DigiLocker KYC API Subscription payment gateway & identity/bank account penny-drop verification.

3. Application Startup Lifecycle & Bootstrapping

App initialization is orchestrated by AppBootstrapper (lib/core/services/app_bootstrapper.dart).

Bootstrapping Order:
1. SharedPreferences & AppConfigService.load() (Fetches remote API URLs & flags).
2. Native Device Orientation (Portrait lock) & System UI overlay configuration.
3. EasyLocalization.ensureInitialized() & HydratedBloc.storage setup.
4. Firebase Core Initialization & Crashlytics fatal error hooks.
5. Service Locator setup (di.init()).
6. NotificationService & DeepLinkService listeners startup.
7. Auth session restoration (AuthCubit.restoreSession()).

3.1 Authentication Route Decision Tree

  1. First Launch: Displays OnboardingPage. On completion, sets has_seen_onboarding = true.
  2. Session Restoring: Displays animated logo splash screen.
  3. Google Sign-In Needs Phone: Renders LinkPhonePage.
  4. Authenticated (Registration Pending): If requiresRegistration == true, redirects to RegistrationPersonalPage (4-step wizard).
  5. Authenticated (Active): Loads property list (HostelCubit.getHostels()), fetches notification count, and opens MainNavigationPage.
  6. Unauthenticated: Renders LoginOnBoardingScreen.

4. In-Depth Feature Specifications & API Integration

4.1 Authentication & Owner Onboarding (features/auth)

Requirements: Support Phone OTP, Google Sign-In, and Staff login. Complete a 4-step onboarding flow for new property owners.

  • Step 1: Personal Details (Name, Email, Alternate Contact, Address).
  • Step 2: Hostel Details (Hostel Name, Gender Category, Address, Total Beds).
  • Step 3: Hostel Images (Cover Photo & Gallery Photos upload).
  • Step 4: Verification Documents (Aadhaar, PAN, Electricity Bill, Bank Passbook).
HTTP Method API Endpoint Description
POST /api/v1/auth/request-otp Triggers SMS OTP dispatch to user mobile number.
POST /api/v1/auth/verify-otp Validates OTP and returns JWT bearer token and owner object.
POST /api/v1/auth/google-login Authenticates using Google ID token.
GET /api/v1/auth/me Retrieves profile data for currently logged-in user.
POST /api/v1/users/complete-profile Submits 4-step owner registration details.

4.2 Navigation & Main Dashboard (features/dashboard)

Requirements: Display daily operational summary, room occupancy breakdown, rent due list, and quick checkout settlement modal. Feature property switcher dropdown on top bar.

HTTP Method API Endpoint Description
GET /api/v1/dashboard/daily-operations Fetches daily check-ins, check-outs, and pending tasks.
GET /api/v1/dashboard/occupancy Returns occupied, available, and reserved bed counts.
GET /api/v1/dashboard/rent-due Returns list of tenants with pending or overdue rent amounts.

4.3 Property Setup & Room Configuration (features/property_setup)

Requirements: Define floor structures, rooms per floor, sharing types (Single, Double, 3-Share, 4-Share, etc.), per-bed monthly rent, amenities, house rules, and weekly food menu.

HTTP Method API Endpoint Description
GET / POST /api/v1/hostels Fetch owner property list / Create property profile.
GET / POST /api/v1/rooms List rooms / Add new room with sharing type & bed count.
GET /api/v1/rooms/floors Fetch floor layout for selected property.
GET / POST /api/v1/food-menu/weekly Fetch / Save weekly meal menu breakdown.

4.4 Bookings & QR Check-In / Checkout (features/bookings)

Requirements: Manage online guest reservations, manual walk-in bookings, QR code verification, room allocation, and checkout settlement calculation.

Checkout Settlement Formula:
Refund Balance = Security Deposit Paid - (Unpaid Rent Dues + Utility Charges + Property Damage Penalty)
HTTP Method API Endpoint Description
GET /api/v1/bookings/owner-bookings Fetches all bookings (Upcoming, Active, Checked-Out, Cancelled).
POST /api/v1/bookings/scan Scans and verifies tenant app check-in QR code.
POST /api/v1/bookings/manual-checkin Creates a manual walk-in booking and check-in record.
POST /api/v1/bookings/checkin Assigns room & bed, finalizes check-in.
POST /api/v1/bookings/checkout Executes checkout and computes final settlement ledger.

4.5 Tenant Management & Bulk Onboarding (features/tenants)

Requirements: Active/past tenant records, manual tenant creation, and bulk CSV onboarding.

HTTP Method API Endpoint Description
GET /api/v1/tenants Fetch list of active tenants for property.
POST /api/v1/tenants/manual Manually registers tenant record and bed allocation.
POST /api/v1/tenants/:hostelId/bulk Uploads CSV file to bulk import tenant records.
GET /api/v1/tenants/hostels/:id/tenant-import-template Downloads standard Excel/CSV bulk import template.

4.6 Payments, Collection & Financial Analytics (features/payments, features/finance)

Requirements: Collect rent via Cash or Online UPI, generate receipts, trigger bulk WhatsApp/SMS rent reminders, and view revenue analytics.

HTTP Method API Endpoint Description
POST /api/v1/tenant-rental/:id/payment/cash Records manual cash rent payment.
POST /api/v1/tenant-rental/:id/payment/upi Records online UPI rent payment.
POST /api/v1/payments/remind-bulk Sends automated bulk rent payment reminders to overdue tenants.
GET /api/v1/finance/stats Retrieves monthly revenue, collections, and pending balances.

4.7 Room Electricity Bills Engine (features/electricity_bills)

Requirements: Define sub-meter billing cycles, input room meter readings, and automatically calculate individual tenant bill shares.

Calculation Formula:
Consumption Units = Current Reading - Previous Reading
Total Room Bill = Consumption Units × Rate per Unit
Per Tenant Charge = Total Room Bill ÷ Active Room Occupants
HTTP Method API Endpoint Description
GET / POST /api/v1/electricity-bills Fetch billing history / Post new room sub-meter entries & cycle.

4.8 Bank Account & DigiLocker KYC Verification (features/bank_account, features/digilocker)

Requirements: Verify owner PAN card via DigiLocker API, execute penny-drop bank account verification, validate IFSC codes, and set primary payout accounts.

HTTP Method API Endpoint Description
POST /api/v1/digilocker/pan-verification Verifies PAN card authenticity and full name match.
POST /api/v1/digilocker/bank-verification Executes penny-drop bank account verification.
GET / POST /api/v1/bankaccounts List bank accounts / Add verified bank account.

4.9 Software Subscription & Razorpay Payment Gateway (features/profile/presentation/pages/subscription_page.dart)

Requirements: Software pricing based on total hostel beds. Service duration plans (1, 3, 6, 12 months) with discount savings, GST 18%, Razorpay order creation, payment verification, and invoice downloads.

Subscription Pricing Model:
Base Amount = Price per Bed × Total Beds × Plan Months
Discount Amount = Base Amount × (Discount % / 100)
Taxable Subtotal = Base Amount - Discount Amount
GST Amount (18%) = Taxable Subtotal × 0.18
Total Payable = Taxable Subtotal + GST Amount
HTTP Method API Endpoint Description
GET /api/v1/subscriptions/plans Fetches software subscription plans & per-bed rate rules.
POST /api/v1/subscriptions/subscribe Generates Razorpay order ID for selected plan and property.
POST /api/v1/subscriptions/verify-payment Verifies Razorpay payment signature & activates property service.
GET /api/v1/subscriptions/my/receipts Fetches tax invoices and payment receipt PDFs (`my_invoices_page.dart`).

6. Network Interceptors & Offline Queue Architecture

  1. Authentication Interceptor: Intercepts every outgoing request and injects Authorization: Bearer <token> and app-type: OWNER_APP.
  2. Session Error Handling: On HTTP 401 Unauthorized or "Owner not found" responses, automatically invokes AuthCubit.logout() to prevent desynchronized state.
  3. Offline Queue Service: ConnectivityInterceptor detects network drops. Mutating requests (POST/PUT) are cached locally by OfflineQueueService and replayed sequentially upon network restoration.
  4. Retry Mechanism: RetryInterceptor applies exponential backoff on transient timeout errors.

7. Developer Setup & Build Commands

# 1. Install Flutter dependencies
flutter pub get

# 2. Generate localizations (assets/translations)
flutter pub run easy_localization:generate -S assets/translations

# 3. Execute Build Runner (for Hive & JSON serializable models)
flutter pub run build_runner build --delete-conflicting-outputs

# 4. Run App in Staging Environment
flutter run --dart-define=APP_ENV=STAGING

# 5. Build Production Release APK
flutter build apk --release \
  --dart-define=APP_ENV=PRODUCTION \
  --dart-define=API_BASE_URL=https://api.stayindia.in/api/v1
